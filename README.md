# Plastikverzicht — Wissenschaftliches Schulprojekt 2026

Eine React + Vite + Tailwind CSS basierte Website für ein Schulprojekt über nachhaltiges Leben ohne Plastik.

## 🚀 Quick Start

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
